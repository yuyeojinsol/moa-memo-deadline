# 📌 모아 — '나에게 보내기' 마감 추출기 (MVP)

카톡 '나에게 보내기' 대화(.txt)를 올리면 할일/일정/링크/아이디어로 분류하고, 마감은 `.ics`(하루 전 알림 포함)로 내보냅니다.

## 노션과의 차이
| | 노션 | 모아 |
|---|---|---|
| 입력 | 앱으로 옮겨 적고 정리 | 기존 습관(나에게 보내기) 그대로, 업로드 1번 |
| 초점 | 문서·DB 구성 | **마감 추출 → 캘린더** |
| 정리 | 사용자가 직접 | 자동 분류 + 틀린 것만 수정 |
| 프라이버시 | 계정/클라우드 | 가입 없음, 원문 미저장, 전화·계좌 마스킹 |
| 비용 | 계정 필요 | 규칙 기반으로 키 없이 동작, AI는 선택 |

## 실행
```
pip install -r requirements.txt
streamlit run app.py
# (선택) LLM_API_KEY, LLM_BASE_URL, LLM_MODEL 환경변수로 AI 분류
python -m pytest
```
지원 형식: 안드로이드, iOS, PC 카톡 내보내기(UTF-8).
